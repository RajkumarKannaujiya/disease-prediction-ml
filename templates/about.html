PROJECT OVERVIEW

About the project

A reproducible Flask application that compares machine-learning classifiers across four public medical benchmark datasets.

Problem statement

Small public health datasets are often used in coursework to demonstrate binary classification. This project builds a traceable workflow around those datasets: it records sources, keeps transformations inside training pipelines, compares multiple models, and reports sensitivity alongside other metrics.

Objectives

  • Provide separate forms based only on variables present in each selected dataset.
  • Train and compare reproducible classifiers without preprocessing leakage.
  • Present holdout metrics, confusion matrices, ROC and precision-recall plots, and local feature contributions where available.
  • Store a minimal local prediction history without personal identifiers.

System architecture

Research workflowSource data → audit and EDA → training-only transforms → cross-validation and tuning → held-out evaluation → versioned pipeline
Application workflowForm → server validation → saved pipeline → model estimate and SHAP contribution → result → optional local history

Technology

Python, pandas, NumPy, scikit-learn, XGBoost, SHAP, Matplotlib, Seaborn, Plotly, Flask, Bootstrap 5, SQLite, and Joblib.

Scope and limitations

This is an academic benchmark project. It has no prospective clinical validation, no independent hospital validation, and no evidence that its outputs improve health outcomes. Dataset populations, labels, missingness, and collection dates limit generalization. See the full disclaimer.
